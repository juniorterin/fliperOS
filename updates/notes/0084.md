- Custom games: when a game has its controller mapped to keys (a .key file in the package, or made in the on-screen menu > Controller configuration), it now opens without seeing the joystick, only the keyboard. A game that finds a joystick often drops the keyboard; the map sends the keys for it. A game with no map still sees the joystick. The change applies the next time the game opens.
- Controller configuration: saving a map that was created or cleared shows "MAY NEED A GAME RESTART" (the game running now may still see the joystick).
- Haptic feedback: modern gamepads with rumble vibrate in the Setup menu, in the FliperOS frontend, and when a frontend or game opens, closes or fails to start. Setup > Joysticks > Haptic events has a preset per event (items, enter, back, systems, open and exit of the frontend), the overall strength and a preview; the web panel has the same rows. Wheels, light guns and arcade panels are left out.
- Cloud backup: the automatic sync is now on by default, backs up every hour and on shutdown, and leaving the Setup sends the settings (and custom folders) right away. The automatic backup is switched on once for every cabinet.
- Web panel > Send packages: drag-and-drop area, with the progress of the upload and of the install (PortProton included).
- PortProton: the install shows apt's progress (the bar no longer sits at 0%). Tasks has a ring loading icon instead of the spinning glyph.
