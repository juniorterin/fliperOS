- **Screen switch: a 15 kHz tube and a 31 kHz monitor on the same cable.** For whoever has a tube and also a PC monitor or an EDTV plasma, and used a dual boot to keep them apart: Video Setup > Screen Switch (also in the web panel) reads which monitor is on the cable (its EDID) and uses that screen's video. The tube keeps its 15 kHz modes; a 31 kHz monitor gets 640x480 and the games' 480p. Each screen keeps its own monitor type, resolution and geometry, and every start begins in the tube's mode. Swap the cable with the cabinet off: with it on, pulling the 31 kHz monitor's cable cuts the signal at once and the cabinet restarts in the tube's mode, and a VGA switch box swaps faster than that. Only on an analog output (VGA, DVI-I), and not tested yet on a real 31 kHz monitor: it stays off until you turn it on.
- **Create package no longer stops at "Making…".** On a cabinet where no art had ever been sent through the web panel, the panel had nowhere to write the list of chosen games: the package was never made and the page waited forever with the button locked. The folder is now created when needed, for everything that uses it.
- **The page says when the cabinet does not answer.** A request that dies without an answer ends the progress bar with the error and frees the button, and an unexpected error in the panel comes back as a message instead of a dropped connection. A task in progress also survives a few lost answers (Wi-Fi, the lab mode tunnel) before giving up.
- **The right file name for a Batocera console.** The name shown while the package is made, and the Download link at the end, are now the file that really comes out (Title.fliperos-retroarch-mesen-s.zip for the SNES with Mesen-S), not Title.fliperos-batocera-snes.zip.
