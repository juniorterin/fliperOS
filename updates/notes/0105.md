- **Packages in parts.** The free plan of Telegram takes files of up to 2 GB, so a custom game package bigger than that now goes in **parts**: `GAME.fliperos-customgame.zip.001`, `.002`... of 1900 MiB each (the last one is smaller). In the web panel, after Create package (one or many) and in the Download of an installed game, a package over 2 GB shows a download link for each part. The parts are cut from the zip that is already on the cabinet while they download, so they take no extra space.
- **Installing a package in parts: double-click any of the parts** (not only the `.001`), on the cabinet's desktop, in a folder or on a USB stick. The install window opens, finds the other parts next to it, checks them (a missing number, parts of different sizes, a last part that is not there), joins them into `~/roms/custom-packages` with a progress bar and installs the game as it does for a zip. Parts chosen together join once; a zip with that name that is already there asks before being replaced. The parts that were in the packages folder go away after joining; the ones on a USB stick stay. Joining needs free space for the whole package once more.
- **Installing from the web panel:** choose or drop **all** the parts together on the Games tab. The page checks the numbering and the sizes before uploading anything, then the cabinet joins the parts (a task with progress) and the game installs by itself, in the group chosen under the area.
- The parts have a file type and an icon of their own (the package icon), so they are not opened as a zip by mistake. For the command line: `fliperos-customgame parts PART` shows the set and what is missing, and `fliperos-customgame join PART` joins it.
