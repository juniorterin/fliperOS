- **Updates download and install themselves**: after the first screen FliperOS looks for an update in the background, and a pending update is applied when you power the cabinet off (not on reboot). The boot no longer waits for the network just to check. "Not now" means it goes in at the next power off.
- The Downloader's *.torrent file* and *Web browser* buttons have icons, and the `.torrent` files in the file picker show a torrent icon.
- Everything in the Setup that downloads (the Downloader, the Scraper, System Update, installing an emulator, a frontend or an extra) first checks the internet. Without it, and with a Wi-Fi adapter, it offers to connect to a Wi-Fi network and then carries on; without Wi-Fi it asks for the network cable.
- The Wi-Fi password (and every password in the Setup, and a hidden network's name) has an on-screen keyboard for the joystick: arrows pick a key, button 1 types it, SHIFT gives capitals and symbols, SHOW shows the password.
- The folder pickers show each disk once: a disk without a label no longer appears twice (by its model name and by its UUID).
- **MAME 2010:** each panel button no longer presses two buttons at once (player 1 and player 2), and Setup > Joysticks > Buttons layout now works in it. The core read the panel twice, as a keyboard and as a RetroPad; now its buttons come only from the RetroPad, and its own Input menu lists Button 1 to 6 on Joy Button 1 to 6, in order.
- The FliperOS menu shows the network use (down and up) between the IP address and the disk.
- The tiles of the FliperOS menu and the Setup stop at the first and the last item instead of going round.
- Video Setup > 480i games is now called **480i hacks** (also in the web panel).
- **Auto scrape keeps going during a game and with the frontend closed**: it is now a service of its own (Setup > System > Services > Auto scrape, after boot by default), at the lowest CPU and disk priority. The frontend shows its progress in Tab > Frontend options.
- **Scraper > Scrape the games runs in the background**: any key returns to the menu while it goes on, and opening it again shows the progress.
- The desktop has a **Home** shortcut to your folders (roms, bios, media, config).
- In /media/fliperos the file manager shows each disk without a label once, by its name (the old UUID path still works, hidden).
- **Frontend**: clones also in the grid and in the full-screen view, with a small CLONE badge; genre, control and button icons; the game's + page shows the buttons on the panel, the description, a second page and the marquee.
- **Web panel**: - and + buttons on each colour setting; the game's buttons as in the button guide.
- Setup > Games > Emulators & Games shows the version of each emulator and of the update.
- PCSX2 opens from the frontend, with the video mode chosen on the cabinet; GroovyMAME no longer shows "Loading" for the ROMs.
- Faster boot: the boot does not wait for Wi-Fi with the radio off, Attract-Mode is only prepared when it is the one that opens, and `i8042.noaux` goes on the kernel line when the kernel says there is no PS/2 mouse port.
