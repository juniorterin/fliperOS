- The Setup's graphical menu is back: since the 0.24 image it always opened in the text menu (a broken file in the graphical interface).
- Cloud backup: "Sign in with Google" like a smart TV, with a QR code on the screen, in Setup > Cloud backup and in the web panel. The backup now carries every setting and what you leave behind: played games, time played, favourites, the emulators' and frontends' settings, button maps. Going back, only what is newer than the cabinet's comes in, and never the monitor or video settings.
- On-screen menu (OSD): legible in any game size; Save and Close at the bottom; profiles (default, this resolution, this emulator, this core, this game) with Save profile as and Delete profile; a Scanlines page with every setting live in the game; a GunCon 2 page while a gun is connected; the video mode and the game's FPS under the title.
- Desktop: the controller is the mouse, and an on-screen keyboard opens by itself in text fields. Every text field of the graphical Setup has the on-screen keyboard too.
- Controller lights (DualSense, DualShock 4, some 8BitDo) turn FliperOS purple; Setup > Joysticks > Controller light picks another colour or turns it off.
- A game whose emulator is not installed yet installs or builds it first, with a progress bar, then opens.
- System logos come with the image, without downloading the Arcadeflow theme.
- Arcade memory with unlocked content (Tekken 3, Tekken Tag, Soul Edge, SF EX, UMK3, Naomi and Atomiswave games...) comes with the system; a game that already has its own memory keeps it.
- OpenBOR: the paks show in the frontends with title art and information from the pak and the Scraper, and each one opens in its own video mode, without black bars.
- Flycast without the mouse arrow in the middle of the game.
- Bluetooth shows in the Setup only with an adapter, and a failed pairing tries again.
- The installer suggests amdgpu on AMD cards that do Vulkan with it.
