- Setup > System > Storage: use a second or external disk. A data disk you plug in (8 GB or more) gets a `fliperos` folder with the whole folder structure (roms, bios, media, nvram, save). Pick the disk in Storage to make the ROMs, BIOS, art, saves and downloads go to it; "Back to the main disk" undoes it, and nothing is deleted. The web panel opens the same screen on the cabinet.
- Frontend: switching systems no longer stalls and the frame rate is smoother (the emulators' files, the games' art and the system icons are read in the background now).
- Frontend: the first button after the cabinet sat idle works. Before, it only woke the screen up and you had to press twice.
- Frontend list: a game with no year and no developer lets the icons rise into the empty line.
- Custom games: a game has a year and a developer (in Add, Edit, the table, the package and the Setup), shown in the frontends. A group can have an icon you choose. The package logo (GAME.logo.jpg, png or webp) is asked for in the Setup's Create package too. In the web panel, a finished package shows the link to download it.
- Windows games (PortProton, Wine and Wine Staging) use Vulkan or OpenGL by the video card's driver: amdgpu and newer Intel and NVIDIA use Vulkan; radeon, nouveau and older Intel use OpenGL. `wine_renderer=vulkan|opengl` in fliperos.conf forces one.
- Dolphin: Wii games open in 4:3, and NKit images no longer show the "NKit Warning". `wii_aspect=16:9` in fliperos.conf brings the wide picture back.
- Web panel > System: opens on Setup, the first tab. Status shows the whole hardware (motherboard, CPU and socket, PCI addresses, the sound output in use, sound cards, disks, connected devices) with a button to copy the full report of the machine, ready to paste into a help request (no IP or MAC addresses). Logs has a Copy log button next to Refresh.
- Cloud backup: the first sync shows a progress bar, in the Setup and in the web panel.
- Desktop: the Onboard on-screen keyboard only opens by itself when you use the joystick.
- Installer: taking the stick out and restarting no longer prints an error in the terminal.
- Haptic feedback vibrates only when the action happens (holding a button doesn't, and in the frontend only when the list moved).
