- Os jogos custom passam a ir num arquivo só, JOGO.fliperos-customgame.zip: a pasta do jogo, a imagem, o vídeo, o texto, as configurações (modo de vídeo, categoria, controles, botões, jogadores), o mapa do controle para o teclado e, nos jogos do Windows, as configurações do PortProton. Ponha em ~/roms/custom (ou na pasta de um grupo) e instale em Setup > Games > Custom games.
- Setup > Games > Custom games mostra os grupos em azulejos, com quantos jogos cada um tem; dentro de um grupo, os jogos com a imagem, mais Add games, Package (fazer um pacote de uma pasta de jogo) e All new.
- O frontend do FliperOS e o painel web voltam a abrir os jogos custom.
- Jogos de PC que só aceitam teclado: o menu na tela de um jogo custom tem Controller configuration, um teclado na tela onde você escolhe qual botão manda cada tecla.
- Os jogos do Windows de um pacote rodam no PortProton, baixado (cerca de 3 GB) na primeira vez que um pacote do Windows é criado ou instalado.
- RetroAchievements: o Setup manda a Web API Key para o painel web, que leva direto a onde ela é copiada.
