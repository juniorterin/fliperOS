- O frontend lê cartuchos do Open Source Cartridge Reader (OSCR) HW5, pelo cabo USB dele: o azulejo do OSCR na linha PHYSICAL MEDIA olha cada slot, um cartucho vai direto ao cartão, dois ou mais dão a escolha, e um cartucho que não responde é escolhido pelo sistema. O PLAY lê o cartucho para uma cópia temporária e o abre no core do RetroArch; o RIP TO FOLDER guarda a ROM e o save na pasta do core. O Boot from media também pode ligar no leitor de cartuchos. Ainda não testado com um leitor de verdade.
- Setup > System > Cartridge reader (OSCR) instala o firmware do FliperOS que o frontend precisa: salva antes o firmware do leitor em ~/oscr, grava o novo pelo cabo USB e confere. O Restore the backup volta o antigo. Este update instala o avrdude, a ferramenta que grava.
- Este é o nível da imagem do FliperOS 0.23: um gabinete com este update tem o mesmo sistema de um instalado pela ISO 0.23.
