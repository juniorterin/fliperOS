- Setup > Joysticks > Controllers / Arcade panel agora é um menu com Map controllers, Keyboard encoder, Add LPT joysticks, Haptic events e Lights.
- Map controllers: oito vagas de player (Player 1 a 8), duas por linha. Para dar um controle a uma vaga, selecione o cartão vazio e segure um botão naquele controle até a barra encher: o cartão o recebe (se a vaga tinha outro controle, os dois trocam). Um controle que já está configurado só muda de cartão; um que ainda precisa de mapeamento ou de layout abre o menu dele para ser configurado. Um cartão com controle abre o menu dele com Enter, onde cada coisa se muda sozinha: Player, Type (painel de arcade ou joypad), Visual layout, Mapping (todos os botões, um botão ou os botões de menu), Buttons layout e Test controller. O nome do cartão selecionado rola.
- O Visual layout do player 1 muda o guia do frontend sozinho (AUTO é o padrão na página Controls).
- Test controller: cada botão, direção, analógico e gatilho acende ao vivo. Os joypads têm desenho próprio: Xbox, PlayStation, GameCube, Super Nintendo, NES, Dreamcast, Saturn, Mega Drive, Neo Geo CD e Nintendo 64; os painéis de arcade mostram a alavanca e os botões do layout deles. Segure Start para sair (ou Esc).
- Um jogo agora abre com os controles na ordem dos players: quando está fora de ordem (em geral no primeiro jogo depois de ligar o gabinete), os controles USB são religados por software na ordem dos players, uns dois segundos, para o Flycast e o Flycast Dojo do Fightcade (que dão a porta 1 ao primeiro controle que o sistema lista) seguirem o player que você escolheu. Controles Bluetooth não são reordenados.
- Odin: o player 1 e o 2 são os controles que você escolheu no Setup (antes ele pegava os dois primeiros ligados).
- Um controle sem player guarda o mapeamento, e um mapeamento pode ser mudado um botão de cada vez.
- Setup > Audio Setup > Stereo or mono: o Mono mistura os dois canais e toca o mesmo som nas duas saídas, para um gabinete com uma caixa só (o padrão continua estéreo). O instalador também pergunta, logo depois do vídeo, e o painel web tem em Audio > Estéreo ou mono.
- O Audio Setup mantém os ícones: não tem mais o resumo em cima; cada item mostra o valor atual (placa, volume, estéreo ou mono, latência) na dica dele quando o cursor está nele. Textos longos nos menus rolam, em vez de serem cortados ou quebrados em mais linhas.
