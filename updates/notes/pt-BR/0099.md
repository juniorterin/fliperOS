- Os jogos de OpenBOR agora abrem no RetroArch, com o core AnyBOR (retrodiv/AnyBOR-libretro): um core libretro do OpenBOR com 322 perfis de motor (OpenBOR 3.0 das builds 3020 a 6391 e o 4.0 até a 8023-dev) que escolhe sozinho o perfil de cada pak, então mods antigos e novos abrem no mesmo core. Ele não vem na imagem: na primeira vez que você abre um jogo de OpenBOR por um frontend, o FliperOS baixa e instala o core sozinho (um pacote de uns 5 MB, com a barra de progresso) e o jogo abre. Cada jogo abre no modo de vídeo que o motor CRT do RetroArch dá a ele, com save states e até quatro jogadores. O motor de Setup > Games > OpenBOR (e o comando `openbor`, com o modo de vídeo por pak e o OpenBOR 3.0 de reserva) continua como era.
- ~/roms/openbor agora é um atalho para ~/roms/retroarch/anybor, a pasta do core. Os jogos que já estavam em ~/roms/openbor (a pasta Paks, Saves, Logs, v3) são movidos para lá um arquivo de cada vez, sem sobrescrever nada: um arquivo cujo nome já está nos dois lugares fica onde estava, e a pasta continua pasta até o próximo login mover o resto. Uma pasta que você já apontou para outro disco não é mexida. A tela Folders mostra ~/roms/openbor como atalho.
- O core inclui o OpenBOR 3400 e 3741, cuja licença proíbe vender o código ou os binários; os textos das licenças estão em /usr/share/doc/fliperos-anybor.
- Testado com três paks no gabinete: Gunman (400x300), Batman SD (320x240) e Moonblade (640x480).
- Setup > Audio Setup: as dicas dos itens de placa, volume, estéreo ou mono e latência ficaram mais curtas, para caberem no balão numa tela de 320x240; o painel web mantém o item Estéreo ou mono com o mesmo nome do Setup.
