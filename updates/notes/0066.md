- Updates no longer stop on "Conflicting values set for option Signed-By": when the same repository is in two apt sources with different keys (WineHQ added by hand next to the Setup's Wine Staging), the FliperOS one stays and the other is turned off, before each update, in the System Update and when installing an Extra. A cabinet already stuck on such an update gets going again with `curl -fsSL https://raw.githubusercontent.com/juniorterin/fliperOS/main/updates/bootstrap.sh | sudo bash`.
- The check of which files an update changes no longer runs out of space, so the warning lists only the files you really changed.
- RetroAchievements: Setup > Games > RetroAchievements and the web panel's Settings sign in to your retroachievements.org account once (only the token is kept, never the password), turn achievements on or off and switch hardcore mode. It works in RetroArch, DuckStation, PCSX2, Dolphin and Flycast. RetroAchievements sits in the Setup's main menu, after Start desktop.
- Cloud backup in the web panel (Settings > Cloud backup): high scores (MAME hiscore and NVRAM), saves and the player's settings go to Google Drive, Dropbox, WebDAV/Nextcloud, SFTP or MEGA through rclone. Both sides keep the newest file and nothing is deleted; Sync now, Send and Receive, or on its own after each game.
- With more than one FliperOS on the network, fliperos.local lists the cabinets and lets you pick one.
- Screen Resolution is now Desktop Resolution, with an icon on the desktop.
- The Setup opens its graphical menu also when the video card is not card0 (it stayed in the text menu, seen on an R9 380); the colour calibration too.
- The 0.24 image's level.
