- **Cheats: a folder for each emulator.** The new `~/cheats` folder (also a network share, in the web panel's Files tab and in Setup > Games > Folders) has one subfolder for each emulator that reads cheats (`mame`, `hbmame`, `ps2`, `namco2x6`, `ps1`, `flycast`, `dolphin`) and one for each RetroArch core that has them (`retroarch/Snes9x`, `retroarch/FinalBurn Neo`...). Put a game's cheat file in its emulator's folder, in the format and with the name that emulator asks for, and it is found when the game starts: no path to set. Each folder has an `_info.txt` that says which, and the wiki page *Cheats* has the whole list.
- **What gets switched on by itself.** GroovyMAME and hbgroovymame now have the cheat engine on (Tab menu > Cheat); PCSX2 and PCSX2x6 have cheats on; Dolphin too; RetroArch applies the cheats a file marks as enabled when the game opens, and **Online Updater > Update Cheats** downloads the libretro database into the same folder; Flycast looks in its folder for `<game file>.cht`. In DuckStation the folder is set, and each cheat is turned on from its menu (Esc > Cheats), as it keeps that per game.
- **Nothing is lost.** The old cheat folders of GroovyMAME, hbgroovymame and Dolphin (`~/.mame/cheat`, `~/.hbmame/cheat`, Dolphin's `GameSettings`) become links to the new folders, with what they held. Keisho, Odin, xemu, Hypseus and OpenBOR have no cheat system, so they have no folder.
