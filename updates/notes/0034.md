- Web panel: three more Setup screens now work from the phone or the PC. The Downloads page has Download BIOS: the last check, the list by state, Check now and the automatic check. The new Scraper page scrapes the art of your games, with the FliperOS scraper or a site such as ScreenScraper (its login is easier to type on a real keyboard), resumes a stopped scrape and downloads the art packs by torrent. The new Install page installs or updates the emulators and the extras that don't come in the image, and checks for a newer version of each emulator.
- NVIDIA on nouveau: the low resolution test now climbs from 320x240 to 640x240 and keeps the first grid you see, instead of going to super resolutions when 320x240 stays black. A GTX 980 Ti showed every mode from 7.15 MHz up. Narrower games are shown at double width, with the same picture on a CRT. Repeat it in Setup > Video Setup > Low resolutions.
- NVIDIA: Video Setup > Video driver recommends nouveau and has Compare the two, with what each driver gives and takes. NVIDIA's own driver only changes resolution in programs that open in Xorg.
- First boot: it no longer asks what opens at power on (the FliperOS frontend is already the default). A short wizard offers the Wi-Fi when the network cable brings no internet and there is a Wi-Fi adapter, then the Button mapping, then the Live screen. Button mapping now refuses a button already given to another input and says which one has it.
- Video driver: on amdgpu, Flycast and Dolphin use Vulkan (PCSX2 and DuckStation already pick it by themselves); back on radeon each one returns to its factory OpenGL renderer. RetroArch stays on glcore. The web panel's FPS also counts games in Vulkan (a small Vulkan layer, loaded after a restart); it does not show Flycast's FPS yet.
- Frontend, Tab > Frontend options: the menu is one scrolling list now. New options: Exit key and Exit buttons (a keyboard key, or panel buttons held together, that close the game; Delete clears them), Power closes game (on: the power button closes the open game, off: it does nothing while a game is open) and Commercial mode with Minutes per coin. In commercial mode a game can only be chosen with credit, each coin adds time, the time running out closes the game, the controller's button 2 does not leave the frontend (the keyboard Esc still does), and a coin-slot indicator shows INSERT COIN or the minutes left.
- The power button with the FliperOS frontend open powers off the cabinet; before, it killed the game's video and did nothing else.
- Booting straight into one game: the Limine menu waits 1 second instead of 3 (any key held still opens it), and the automatic login no longer waits for the network. Reboot and power off: a service that ignores the stop request is killed after 10 seconds, not 90.
- Web panel: the browser never keeps the pages (every visit gets the cabinet's current version); the Live screen stays 4:3 on a phone; Downloader torrents run faster (more peers, a bigger write cache, normal disk priority).
