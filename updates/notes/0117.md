- **Game Packages see the games of a Batocera disk or a network folder.** With the Batocera filesystem in use (External storage, a Batocera HD or a RetroNAS share), each console now shows up in Create package with its games, art and edited details, read where they are. The package comes out in the format of the core that opens the console (the SNES with Mesen-S becomes Title.fliperos-retroarch-mesen-s.zip), so whoever installs it gets the games, with or without a Batocera. Only what the frontend lists counts as a game: Batocera's images, videos, gamelist and readme files stay out, and a network folder whose server is off is skipped without waiting for it.
- **The MAME filters only for arcade.** In Create package, genre, players, buttons, control, decade, maker and clones appear only for the arcade emulators and cores, not for a console.
- **Download BIOS looks at the Batocera consoles too.** Each console asks for the BIOS of the core that opens it; nothing is written inside the console folders.
- **The arcade consoles of a Batocera filesystem are arcade everywhere.** Its mame, naomi, atomiswave, neogeo and fbneo folders get the MAME game list (real titles, categories, clones) and the arcade art, and the Pixelcade/ZeDMD shows the arcade marquee for its Naomi, Atomiswave, Model 2/3 and FBNeo games, like the same games in ~/roms.
- **Net play, link play and parties with a Batocera console.** They go by the emulator that opens the console, so the SNES of a RetroNAS and ~/roms/retroarch/snes9x on another cabinet are the same game.
- **FliperOS Matchmaker (still hidden): the groundwork for online parties.** The cabinet gets the WireGuard tools and the tunnel the online party will use, direct or through a relay. Nothing changes on screen yet.
