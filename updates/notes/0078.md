- Custom games: new video mode "240p hack" for games that only run at 640x480 (Mugen and other Windows games under PortProton): the game sees 640x480 and the tube gets 240p from Switchres, without tearing. Seen on the cabinet with KOF Zillion.
- Custom games: a Windows game can open with PortProton (the default), Wine or Wine Staging, chosen when creating the package in the Setup and in the web panel. If the chosen one is not installed, the game opens with another one.
- The on-screen menu (OSD) now opens over games that draw through X without OpenGL (Mugen, Fightcade) and over every PortProton game, where it did not open before.
- Web panel, custom games: the field for the "Other" video mode (WIDTHxHEIGHT@HZ, e.g. 320x240@60) can be typed in again in Add and Edit; before, it was squeezed to a sliver, and in Edit it did not show up at all.
