- The desktop on a 31 kHz monitor no longer opens with an "out of frequency" message. When the boot mode of a 31 kHz cabinet comes from an EDID (a DisplayPort or HDMI to VGA converter, for example), the X configuration had no mode of its own and the X picked a mode from the EDID that the monitor does not accept. A 31 kHz monitor now always gets its 640x480 at 31.5 kHz in the desktop, and this update rewrites the X configuration (`/etc/X11/xorg.conf.d/10-fliperos.conf`) on the cabinets already set to 31 kHz. Other monitors are not touched. Open the desktop again after the update (or restart the cabinet); if it still shows the message, send `/etc/fliperos/fliperos.conf` and `~/.local/share/xorg/Xorg.0.log` to the Telegram group.
