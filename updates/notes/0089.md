- Setup > Games > Folders is now two things. **Folder shortcuts** is what used to be called Link: send one FliperOS folder to another disk, like a shortcut. The list says what each folder keeps and where a shortcut points, "How shortcuts work" explains it with an example, and the actions have clearer names: "Point it to a folder on another disk", "Change where it points" and "Remove the shortcut". Pointing a folder of one system at a folder that holds many consoles (snes, megadrive, psx...) now asks first, because the games would not show up. **External storage** is for a whole disk.
- Setup > System > Storage moved to Games > Folders > External storage > FliperOS folders (the web panel keeps it as "External storage", right after Folders, opening on the cabinet). It works the same: use a second disk for the ROMs, BIOS, art, saves and downloads, only prepare the folders, or go back to the main disk.
- External storage > FliperOS folders > Format this disk: erases the partition of a disk and makes it new, as ext4 (the best for FliperOS, but Windows cannot open it) or exFAT (Windows and Mac open it, but it is slower and has no links). It asks twice, with the NO already selected, and the second time with Cancel first. It refuses a disk that also holds the system, one the FliperOS folders or a Batocera filesystem are using, one with a packed game folder, and one with RAID, LVM or encryption. The update installs `exfatprogs` for exFAT. Not tried yet on a real disk.
- External storage > Batocera filesystem: a disk that keeps the games the way Batocera does (`batocera/roms/snes`, `megadrive`, `psx`...) can be used where it is. Each console folder FliperOS knows becomes a system in the frontends, with the core FliperOS prefers for it, and in "Cores of the consoles" you choose another core for each console, or the standalone emulator when there is one. Nothing is copied, moved or written inside the console folders. "Use it" also makes the folders beside `roms` (`bios`, `saves`, `nvram`, `media`, `snap`) the ones FliperOS uses, and makes the FliperOS folders Batocera does not have (`namco2x6`, `fightcade`, `hypseus` and `custom-packages`) on the disk. "Stop using it" puts everything back. Not tried yet on a real Batocera disk.
- When a disk with a Batocera filesystem is plugged in, or the cabinet turns on with it connected, the FliperOS frontend asks once whether to use it, with the Batocera logo (NO is the one selected). Such a disk no longer gets a `fliperos` folder written on it. A new, plain disk gets the same kind of one-time question now: the frontend offers to use it for the ROMs, BIOS, art and saves, and tells where to change it later. A disk without a label is no longer listed twice in the disk list.
- The screens and the web panel that tell you where to put something now say where the folder really is when it is on another disk, for example `~/roms/custom-packages (on HD: batocera/roms/custom-packages)`, or that the disk is off. This is for the custom game packages (Install games, Create package, the panel's pages and messages) and for the folders made on a Batocera disk.
- Scraper: scraping with the site works when `~/media` is on a hard disk in exFAT, FAT or NTFS. It used to fail on every folder ("Could not create the folders"), because those disks do not keep links; the Skyscraper and ES-DE link folders now stay on the main disk and point to the art on the other one.
- Setup: entering an item zooms the screen in from where you left it, and going back zooms out, in 0.3 seconds. The animated background keeps going underneath. The Setup and the frontend now ask for vsync, so a frame no longer changes in the middle of the picture (tearing); the games keep deciding their own vsync. Not seen yet on a CRT: the timing of the frames there still has to be measured.
- Frontend, the menu of a game (PLAY, the star, the +): it opens animated, the tile you pick moves, and pressing plays its effect before it acts. PLAY lights up green and the picture switches off like a tube TV, to a bright line and a dot, just as the game opens (0.30 seconds later); the star sparkles and the menu closes; the + turns and dives into its page; Esc shrinks the menu. Sharp steps with no blurred scaling. Not seen yet on a CRT.
