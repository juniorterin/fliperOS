- **FliperOS 0.30.** This update is the level of the new ISO, 0.30, which gathers updates 105 to 116: a cabinet installed from it and one that applied the updates end up with the same system.
- **Arcade monitor on the VGA of an APU: a picture from the boot.** On the AMD APUs whose VGA comes from a DisplayPort bridge chip (Kaveri, Trinity and Richland: A4, A6, A8 and A10 with the VGA on the motherboard), an arcade monitor that the card doesn't detect (often behind a J-PAC) now gets a picture: right after the system reads the bridge chip at boot, FliperOS turns the output on, as CRT Emudriver does on Windows. A monitor that is detected (a PVM) works as before. It takes effect at the next boot.
- **The FliperOS Matchmaker preview leaves the lists until it can play matches.** It is no longer offered in Setup > Games > Frontend, the first boot or the web panel. A cabinet that already starts in it keeps doing so until you pick another frontend.
