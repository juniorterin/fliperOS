- Odin, the emulator of the Sega Hikaru (Air Trix, Brave Firefighters, Planet Harriers, NASCAR Arcade, Star Wars Racer Arcade, Virtual-On 4) and of the Gaelco 3D boards (ATV Track, Smashing Drive, Football Power, Radikal Bikers, Speed Up, Surf Planet), is now a system of its own: its games go in the folder ~/roms/odin (it is there from now on, like the others, with ~/bios/odin, ~/nvram/odin and ~/save/odin beside it). It does not come in the image: the first time you open one of its games from the frontend, FliperOS downloads and installs Odin by itself (a package of about 5 MB, with the progress bar; it can also be installed in Setup > Games > Emulators & Games). Each game is a MAME set (.zip or .7z), and the Hikaru ones also need the shared sets hikaru.zip and mie.zip in ~/bios/odin (or in ~/bios/mame, or beside the games). On an AMD card with the amdgpu driver it draws in Vulkan; with the radeon driver or an Intel chip, in OpenGL (it needs OpenGL 4.3, so an Intel HD of the Ironlake generation cannot run it). On a 15 kHz tube it opens at 320x240, the 4:3 picture of the board; on 25/31 kHz monitors and LCDs, at 640x480. It starts in full screen with VSync on, and it has its own menu (Escape, F10 or the Guide button, and coin + button 1) for the controls, wheels, light guns and linked cabinets. The first time you play a game, calibrate its controls in its test menu. It shows up in every frontend as Odin, with the game names from the GroovyMAME list. Tested in a virtual environment, not yet on a CRT.
- The games of the HBMAME folder that come inside the zip of their parent (a merged set, like ssf2t.zip with its hacks) now show up in the game lists: the list uses HBMAME's own game list when it is installed, and it is made again right after HBMAME is installed, without waiting for the next boot.
