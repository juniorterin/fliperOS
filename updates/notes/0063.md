- The frontend reads cartridges from the Open Source Cartridge Reader (OSCR) HW5, over its USB cable: the OSCR tile in the PHYSICAL MEDIA row looks at each slot, one cartridge goes straight to its card, two or more give a choice, and a cartridge that doesn't answer is picked by system. PLAY reads the cartridge into a temporary copy and opens it in the RetroArch core; RIP TO FOLDER keeps the ROM and its save in the core's folder. Boot from media can also start on the cartridge reader. Not yet tried with a real reader.
- Setup > System > Cartridge reader (OSCR) installs the FliperOS firmware the frontend needs: it saves the reader's firmware to ~/oscr first, writes the new one over the USB cable and checks it. Restore the backup puts the old one back. This update installs avrdude, the tool that writes it.
- This is the level of the FliperOS 0.23 image: a cabinet with this update has the same system as one installed from the 0.23 ISO.
