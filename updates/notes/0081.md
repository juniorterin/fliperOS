- Cloud backup now keeps your custom folders (Setup > Games > Folders). Until now they were left out, so a new install signed in to the same cloud account came back with every setting except them. From the next sync with settings on, the list of custom folders goes to the cloud; on a new install, signing in links each folder again as soon as its disk is connected. A custom folder whose disk is not there yet waits and is linked on a later sync.
- Folders set before this update reach the cloud on this cabinet's next sync with settings. If you already reinstalled, set them once more on the new install and they are kept from then on.
