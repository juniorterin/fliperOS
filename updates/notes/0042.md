- A cabinet installed from an older ISO now gets the same FliperOS packages as the latest ISO over the network. Updates used to bring only the scripts and settings, so a cabinet that was never reinstalled kept old builds. This update brings Attract-Mode Plus 3.2.3 fliperos4 (joysticks in the kernel's order, a picture on 1st-generation Intel HD, the screen released when it closes) and GroovyMAME's KMS SDL, so GroovyMAME runs in KMS without Xorg on these cabinets too. It also installs ffmpeg (frontend videos) and the AMD video decoder used by the live screen where they were missing.
