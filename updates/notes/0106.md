- **Packages in parts: you choose the size of each part.** In the web panel, the block that lists the parts of a package now has a number field, **Size of each part**, in MB (1 MB = 1 MiB). It starts at **2000**, the biggest file that Telegram's free plan takes; with Telegram Premium type 4000. This replaces the fixed 1900 MiB parts of the last update. Changing the number redoes the list at once, and the value is remembered in the browser. The field is also there when the package is bigger than 2000 MB but fits in one part at the size you chose: the block says it is not split and keeps the field, so you can go back.
- The last part is always the smaller one. The names go from `.001` to `.999`, so a size that would need more parts is refused, and the panel says the smallest size that works. The parts you already have, cut at any size, install as before: double-click any part, or drop them all in the Games tab.
