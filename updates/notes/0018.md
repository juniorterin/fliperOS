- **FliperOS frontend** is the default: game lists of its own (no Attract-Mode needed), grid of three per row and full screen with four thumbnails, game videos everywhere, animated moves, each game list remembers where you stopped.
- **Automatic scrape**: the frontend fetches the missing art, logo, video and info of every game by itself, torrent packs first. Tab > Frontend options shows the progress. Setup > Games > Scraper uses the same scraper.
- **Vertical monitor**: the frontend, the Setup menu, the boot screen and the terminal now stand upright (Video Setup > Monitor Orientation).
- **GroovyMAME** opens the game straight away: no warnings screen, no "Initializing".
- **Web panel** at http://fliperos.local: games, files, ROM filter, downloads, settings, terminal, live screen with sound and pages for OBS.
- The power button closes a game opened from the web panel instead of turning the cabinet off.
- **What's new**: after an update or a new version the menu shows what changed, once. Setup > System > What's new shows it again.
- Updates now show what they change before asking to apply.
- RetroFE and the Model 2 Emulator (Wine) are gone; DuckStation (PS1) can be installed from Setup > Emulators & Games.
- Smaller boot files (no NVIDIA firmware in the initrd).
