- Custom games: packages now live in one folder, ~/roms/custom-packages (the ones you already have move there in this update). Setup > Games > Custom games has Install games and Create package; the web panel has the tabs Games, Install packages and Create package. Installing asks the group (the last one used comes marked) and, at the end, whether the package can go.
- Custom games: Delete group, in the Setup and in the web panel (before, a group only went away when its folder was empty, and an empty group never did).
- Custom games: the package check lists every problem at once. The minimum is the game folder and a .cfg with name, platform and exe or command; without a video mode the game opens in 640x480i. A folder laid out like a package (GAME.jpg, GAME.mp4, GAME.txt, GAME.key, GAME.ppdb and GAME.cfg next to the GAME folder) fills in the art and settings by itself.
- Web panel: package cards like the frontend's (picture, video, scrolling text, control icons), 10 per page with search, filter and order; Create package has a card preview and Test on the cabinet (the game opens from its folder without installing, and the controller map made in the test goes into the package).
- A custom game without a controller map opens the on-screen Controller configuration by itself (Save, even empty, stops it asking).
- Desktop: Games > Custom games and Games > PortProton in the menu, and a PortProton shortcut on the desktop when it is installed.
- Wheel calibration no longer closes by itself when the wheel turns: the controller stops working as a keyboard while it runs (turning the wheel sent arrow keys, and the calibration took them as Esc), and a wheel's centre is now the middle of its travel.
- New wheel screen in the graphical Setup, over the menu's background: the wheel turns with yours in degrees and the pedals fill up; then every button lights up in its real place on a drawing of the controller (a wheel, a joypad, or rows for a panel); then the force feedback pulls both ways and shakes. Hold any button to go on.
- In the menus, a wheel moves only with its d-pad and buttons: the cursor no longer runs by itself with the wheel off centre or a pedal at rest.
