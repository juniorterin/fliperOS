- **Custom games is now Game Packages**, with three areas in the Setup and in the web panel: **PC Games** (the PC games, scripts and your own emulators, as before), **ROMs** and **Create package**, which first asks whether the package is of a PC game or of ROMs.
- **ROM packages.** Pick an emulator or a RetroArch core, mark its games and give the package a title: it comes out as TITLE.fliperos-EMULATOR.zip (FightingGames.fliperos-mame.zip, Shmups.fliperos-retroarch-fbneo.zip) with the ROMs and, each one optional, the BIOS and parent sets the games need (from the MAME game list), each type of art in ~/media on its own (pictures, videos, logos, boxes, marquees, LED marquee art, texts), the memory (NVRAM), the saves, the cheats and the per-game settings. On another FliperOS it installs everything back in the same folders: from the ROMs tab (a package sent there installs right away), from the Setup, or with a double-click on the desktop. A file the cabinet already has with other contents (your own save, a ROM of another version) is only replaced if you say so.
- **A group of its own.** A ROM package can bring a group with the system logo you choose: in the frontends it is a system with those games, each one opening in its own emulator, with its title and art.
- **Picking the games (web panel):** the list on the left with the frontend filters and a MAME filter (genre, players, buttons, control, decade, manufacturer, clones), all adding up, and the selected games in a column on the right. The **+** next to a game opens its details (title, year, manufacturer, category, players, buttons, control...), to change or fill in, with lists of the values that already exist, and a preview of its art. What you save goes to the frontends' game lists and travels in the package.
- **Emulators & Games > Restore FliperOS settings.** Puts an emulator's settings back to the FliperOS ones (RetroArch, GroovyMAME, HBMAME, Flycast, PCSX2, PCSX2x6, Dolphin, DuckStation, Keisho, Odin, xemu), and the Setup's own (buttons, monitor, latency) are applied again. The current settings go to ~/config-backup, and ROMs, saves, memory and cheats stay. Also in the web panel, on each emulator.
- **Web panel:** the links of the site in the side bar (Share, the wiki, GitHub, the Telegram group), and in PC Games and ROMs an invitation to the Telegram group, where the community shares game packs. Game Packages opens in about a second (it took four) and shows a loader while it reads.
