- Namco System 246 and 256 games: PCSX2x6, a fork of PCSX2 for those arcade boards, is installed next to PCSX2 as its own emulator. Put each game (a NM00000.acgame file and the folder with its boot.elf and image) in ~/roms/namco246 or ~/roms/namco256; the dongle (NM00000.ps2) goes in ~/save/namco246|256, the arcade BIOS in ~/bios/namco246|256 and the game memory is kept in ~/nvram/namco246|256. It opens in Vulkan at 640x240 like the other emulators, with the panel buttons mapped as in Setup > Joysticks > Button mapping, and it has its own icon in Setup > Emulators & Games.
- BIOS download now uses RetroBIOS first, file by file with the checksum checked, and the old pack only as a reserve. It also asks for the Namco arcade BIOS and the DuckStation BIOS. The Tab menu of the frontend shows a BIOS DOWNLOAD box next to AUTO SCRAPE; both leave the menu when everything is done.
