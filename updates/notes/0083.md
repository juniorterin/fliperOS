- Keisho now runs Model 3 too, and Supermodel is gone. Keisho comes ready as a FliperOS package, so Model 2 no longer has to be built on the cabinet. The update installs it and then removes Supermodel. Your Model 3 memory files (~/nvram/model3: high scores, settings, link roles) stay, because Keisho reads Supermodel's format.
- Keisho follows the video card like Flycast and Dolphin: Vulkan with the amdgpu driver, OpenGL with the others. A choice made in the emulator's F10 menu stays.
- The desktop's Games menu has Model 2 and Model 3, both in Keisho. In the frontends, the Supermodel screen is now called Model 3; its play counts move with it and favourites stay.
- Link games: Scud Race, Daytona USA 2 and Dirt Devils now link through Keisho, with the same cabinet files as before. They were tested in Supermodel and have not been raced in Keisho on cabinets yet.
- Model 3 in Keisho has not been timed on a slow processor yet (Supermodel needed its CPU slowed down on an i3). If a game runs slow, please tell us.
- Custom games: a game can have a logo. Put GAME.logo.png in the package (or next to the game folder, or logo.png inside it); the frontends show it over the picture, and a game's own logo replaces the sample one.
- Custom games > Create package > Test on the cabinet: with the game open, "Take a photo" and "Record 10 s" capture the cabinet's screen into the package's picture and video (the video needs ffmpeg, which is on the cabinet).
- The Custom games page of the web panel has a new look: the package structure is easier to read, with the tabs, groups and game tiles redesigned.
