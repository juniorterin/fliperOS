- The Model 2 emulator SM2-Emu is now called Keisho and lives at github.com/Keisho-Emu/Keisho. Cabinets that have it built rebuild it during this update from the new address (a few minutes). Its settings, saves and source move to the new folders (~/.config/keisho/keisho.ini, ~/.local/src/keisho) and stay as you left them. Old save states are converted by the emulator the first time they are loaded.
- The game outputs patch (gun recoil, ammo, life, round wins and credits on port 8000) is now part of Keisho itself, so FliperOS no longer applies it. The GunCon 2 aim fix (keeps the aim when the gun misses the beam for a moment) is still applied, rewritten for the new code.
- The Model 2 icon in the desktop menu, the Setup and the site is Keisho's new logo.
