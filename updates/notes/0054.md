- Party for MAME games (wired local network only, no internet): every GroovyMAME game of two or more players now has PARTY PLAY, for up to 4 players on 2 to 4 cabinets, each with its own controllers. The cabinets run on the same frame like an arcade link board, with no input delay: on the cable the other players' controls arrive within the frame. Every cabinet starts the game from its factory memory and settings, on the same clock, without the hiscore plugin; your own saved scores and settings stay as they were.
- GroovyMAME is now built by FliperOS from the source of the same release (MAME 0.289, Switchres 2.22f) with the lockstep patch: this update replaces the GroovyMAME package. Setup > Emulators & Games can now also build the newest GroovyMAME with the same patches, so the party keeps working: it compiles the whole MAME on the cabinet and takes hours (20 GB free on the disk).
- Frontend list: when other cabinets play the same game in separate parties, its row at the top gets a green [+] and how many parties there are; button 1 opens one row per party, with the cabinet that opened it, and from there you join the one you want.
