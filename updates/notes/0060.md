- A CRT on a DisplayPort output (through a DisplayPort-to-VGA converter) now gets super resolutions, as on HDMI and DVI-D: the games and the menus run from 25 MHz up. One converter showed no picture at all below that, at 15, 25 and 31 kHz. Cabinets already set up this way are fixed by this update; the change counts from the next restart.
- On HDMI, DVI-D or DisplayPort, a 25 kHz monitor (or a 31 kHz one whose boot mode is below 25 MHz) gets a boot EDID in super resolution instead of the 512x384 one, which converters do not show.
- The web panel has Monitor type, Boot resolution and "Back to the previous monitor" in Settings > Video: the way back when a new monitor leaves the tube without a picture. Its groups follow the order of the Setup.
- The text button mapping of the first boot draws the panel: the control being asked blinks, the ones already pressed turn green. The first boot also applies the updates published after the ISO as soon as there is internet.
- Wine Staging installs again on the image (it failed on a JACK library conflict).
