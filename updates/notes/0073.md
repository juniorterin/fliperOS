- Custom games travel as one file, GAME.fliperos-customgame.zip: the game folder, picture, video, text, settings (video mode, category, controls, buttons, players), the controller-to-keyboard map and, for Windows games, PortProton's settings. Put it in ~/roms/custom (or in a group folder) and install it from Setup > Games > Custom games.
- Setup > Games > Custom games shows the groups as tiles with their game count; inside a group, the games with their picture, plus Add games, Package (make a package from a game folder) and All new.
- The FliperOS frontend and the web panel can open custom games again.
- PC games that only take the keyboard: the on-screen menu of a custom game has Controller configuration, a keyboard on the screen where you choose which button sends each key.
- Windows games in a package run in PortProton, downloaded (about 3 GB) the first time a Windows package is created or installed.
- RetroAchievements: the Setup sends the Web API Key to the web panel, which links straight to where it is copied.
