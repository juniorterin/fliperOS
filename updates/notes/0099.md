- OpenBOR games now open in RetroArch, with the AnyBOR core (retrodiv/AnyBOR-libretro): a libretro core for OpenBOR with 322 engine profiles (OpenBOR 3.0 builds 3020 to 6391, and 4.0 up to 8023-dev) that picks the right profile for each pak by itself, so old mods and new ones open in the same core. It does not come in the image: the first time you open an OpenBOR game from a frontend, FliperOS downloads and installs the core by itself (a package of about 5 MB, with the progress bar) and the game opens. Each game opens in the video mode the RetroArch CRT engine gives it, with save states and up to four players. The engine of Setup > Games > OpenBOR (and the `openbor` command, with the per-pak video mode and the OpenBOR 3.0 fallback) stays as it was.
- ~/roms/openbor is now a shortcut to ~/roms/retroarch/anybor, the folder of the core. Games already in ~/roms/openbor (the Paks folder, Saves, Logs, v3) are moved there one file at a time, nothing overwritten: a file whose name is in both places stays where it was, and the folder stays a folder until the next login moves the rest. A folder you already pointed to another disk is left alone. The Folders screen lists ~/roms/openbor as a shortcut.
- The core includes OpenBOR 3400 and 3741, whose license forbids selling the code or the binaries; the license texts are in /usr/share/doc/fliperos-anybor.
- Tested with three paks on the cabinet: Gunman (400x300), Batman SD (320x240) and Moonblade (640x480).
