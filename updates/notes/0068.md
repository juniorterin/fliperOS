- RetroAchievements: each unlocked achievement shows over the game for 5 seconds, in a bar like the volume one: a trophy with a spinning ring, the title (it scrolls when long) and a line that empties. It fits any game resolution and the vertical monitor, in RetroArch, Dolphin, PCSX2, DuckStation and Flycast; the emulators' own notifications stay off. The Pixelcade/ZeDMD marquee shows it too, now from every emulator.
- Frontend: a yellow trophy next to FAV and PLAYED with how many achievements you have and how many the game has (3/24), only where the game's emulator gives achievements. It needs your account's Web API Key (retroachievements.org/settings), saved in the RetroAchievements menu or in the web panel. Disc games (PlayStation, PS2, GameCube, Dreamcast...) use RetroAchievements' RAHasher, which now comes with the system.
- Game menu: those games have a trophy before the "+" that lists all their achievements, fetched from the site right then: the ones you have, then the ones still to get, with title, description and points.
- Flycast updated: its achievements go to the bar instead of its own notice.
- Controller light: the default "FliperOS" style is a purple roulette on the 8BitDo Ultimate 2 in the menus and purple/pink rings during games; the solid colours are stronger. An 8BitDo with no profile gets profile 1, and the Setup says to press the pad's profile button.
- Desktop: the on-screen keyboard is Onboard, docked at the bottom, opening in text fields and closing with a click outside.
- Game shortcuts: Tab > Frontend options > Frontend controls has EXIT GAME and EMULATOR MENU. By default, coin + Start held for a second closes the game and coin + button 1 opens the emulator's own menu; buttons of several players can be joined (P1 START + P2 START).
- On-screen menu (OSD): Volume at the top, Configuration (everything else, with Save), Emulator menu, Close and Quit.
