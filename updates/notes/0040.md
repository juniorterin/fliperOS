- Custom monitor (Geometry): the frontend, the Setup and the desktop now use the same video mode as the games. Before, only the games followed the saved crt_range, and the menus stayed on the kernel's table mode, several centimetres off to one side on some tubes. The update rebuilds the boot mode of a cabinet that already has a Geometry saved, so it needs a reboot. Reset Geometry goes back to the monitor's preset.
- Light gun (GunCon 2): the screen lights up on a shot (Setup > Joysticks > Light gun flash: Pulse, Hold or Off), so the gun finds its aim over dark parts of the picture. A shot off the screen is seen as off the screen by every emulator, and the right button is MAME's button 2 and 3, so reloading works in the games that use it. New Setup > Joysticks > GunCon 2 menu with the gun's state, Calibrate and the numbers, and a GunCon 2 group in the web panel. The frontend shows a pistol for the light gun icon.
- GroovyMAME: the frontend opens it in its own Xorg when the screen has no mode for it, and an off-screen aim stays off the screen in KMS. GroovyMAME in KMS (each game in its own mode, no Xorg) and RetroArch in Vulkan on amdgpu come with the 0.20 ISO: they need packages and a build that only the ISO carries, so on an updated cabinet GroovyMAME stays in its own Xorg and RetroArch in glcore.
- Telegram: a 640x240 screenshot is posted in 4:3, never stretched.
