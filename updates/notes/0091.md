- Setup > Audio Setup > Menu sounds (with a new icon): six sounds, each with its own file and volume: the cursor moving, Enter, Back, a game opening, a game closing and an alert dialog. A file picker chooses each file (WAV, OGG, MP3 or FLAC, in ~/media/fliperos-sounds), and each event has Play, Use the default and No sound. FliperOS comes with a set of retrowave sounds (soft sine waves with a warm echo), copied to that folder the first time. Opening the frontend, the desktop or the shell from the menu plays only the open-game sound.
- Frontend, Tab > Frontend options > FRONTEND SOUNDS: the same six sounds as the Setup, one set shared by both (change a file or a volume in either place and the other follows), plus the music: a music file, or a subfolder of ~/media/fliperos-sounds/music played at random, its volume, PAUSE MUSIC (off by default: the music keeps playing under a preview video's sound) and the volume of the game preview video. The music stops when a game opens and goes on with the next song when you are back. In a game's menu, PLAY plays only the open-game sound.
- Frontend, a bar with the song's name slides in when a song starts, like an unlocked achievement: a circle with a note and a comet running around it, the name and a green line that empties. The bar is only as wide as the name needs and stays clear of the screen's edges; a name that does not fit runs, and the bar stays until it gets to the end. It also shows when you come back from a game.
- Frontend, the sound of a game preview video now comes out together with its picture. With Live screen sound the sound reached the speakers about 0.3 seconds after the picture; the frontend measures that delay when it opens and after each game, and the picture waits that long.
- The songs are not part of FliperOS (the Pixabay licence does not let a song be handed out on its own): put MP3, OGG, FLAC or WAV files in ~/media/fliperos-sounds/music. The first one to play is "BurtySounds - Retrowave.mp3", when it is there. Credits for the three songs the cabinet was set up with (BurtySounds, Musinova and kaazoom, on Pixabay) are in the README.
