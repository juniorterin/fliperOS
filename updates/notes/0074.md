- Cloud backup is much faster: sending and receiving are one pass each instead of one per folder, so the cloud is listed once (on Google Drive, a few requests instead of one per folder). Files the system downloads or rebuilds again (Versus detectors, the KOF patch, lock files) and folders that went twice no longer go up.
- Cloud backup shows its progress: the bar in the web panel's tasks and in the Setup fills as files are checked and sent ("Sending: 120 of 950 files"), and the first sync after Sign in with Google shows its percentage.
- Two games closed at the same time no longer sync with the cloud twice in a row.
- Web panel: System > Settings is now System > Setup, the whole Setup of the cabinet with the same groups and items in the same order. What needs the tube or a controller in hand (the geometry grid, colour patterns, button mapping, the gun targets, the output test...) has Open on the cabinet: that screen opens on the tube, and what was on screen comes back after it.
- New in the web panel's Setup: Folders (another disk for each folder), custom frontends, Quirks with the USB devices connected, Bluetooth (look for, pair, connect, forget), the controller light, System Update and the AttractPlus ROM List.
- Custom games in the web panel (System > Setup > Games > Custom games): the groups and games with their pictures (open, edit, make a package, delete), new packages and uploading a .zip, and Add a game.
- Add many custom games at once in a table: rows typed or picked in lists (group, type, folder, the .exe found in it, video mode, category, players, buttons, controls, picture and video), imported from a folder with one subfolder per game, or pasted from a spreadsheet. Check marks each wrong cell with the reason; Windows and Linux games are copied to ~/games and packed, like an installed package.
- Setup: the folder and file picker keeps the same height in every folder, and a file named like "Game (USA).zip" shows its whole name.
- Web panel: clicking a group in System > Setup no longer replays the tabs' animation, opens the group at once with the last reading (refreshed in the background), and shows a spinner while the cabinet answers; a line separates the groups from their items.
