- Fightcade: Naomi and Atomiswave games (Marvel vs. Capcom 2 and the rest) open. The Fightcade's Flycast now gets the arcade BIOS (`naomi.zip`, `naomi2.zip`, `awbios.zip`, `dc_boot.bin`) from `~/bios/dc` every time Fightcade starts, only the ones it doesn't have yet. Before, the game stopped at "cannot load BIOS naomi.zip" and closed.
- Windows games on Wine, Fightcade's FBNeo included: they can change the screen mode now. The 32-bit XRandR library (`libxrandr2:i386`) comes with Wine, and this update installs it where Wine is already installed. Before, a 32-bit game could not switch modes: FBNeo opened a black window with "Problem setting '384x224' display mode" instead of full screen at the game's own resolution.
- Web panel: Fightcade no longer breaks the panel. While its lobby or a game without the FPS layer (FBNeo, MUGEN) was open, the panel's status failed, and "Playing now" and the Live screen stopped answering. Now those games show "--" in place of the FPS. The Fightcade emulators (Flycast, FBNeo, FBA, SNES9x) count as the game on screen, with the name of the set, so Close the game finds them too.
- Fightcade: the web panel shows the frame rate of FBNeo, FBA and SNES9x (the Wine emulators; it was `--`, about 59.6 FPS in Street Fighter II CE). The room now opens with FliperOS' 32-bit layer, which only those emulators load.
- Button mapping: GroovyMAME opens with the panel's six buttons however the mapping was saved (web panel, graphical menu, plugging a controller, the update). Before, only the text Setup also turned on the `fliperos` controller map in `mame.ini`, and the others left GroovyMAME with MAME's default controls.
- Custom games: Create package > Test records 30 seconds at 60 frames per second, with the game's sound (it was 10 silent seconds), and tells you when the sound didn't get in (Live screen sound off). Photos and videos are always exact 4:3.
- Custom games: "Does the game already work with the joystick?" in Create package (web panel and Setup): the package then carries an empty key map, the on-screen menu doesn't ask for one and the joystick isn't hidden from the game.
- Custom games: Test on the cabinet has a Close button while the game opens or is open, shows the end of the game's log if it closes by itself, and refuses a command pasted as `command=(...)`.
- Frontend: a video with no sound track plays anyway.
