- On-screen menu (OSD), in a game: new Media capture item, with a camera icon. Thumbnail takes a picture of the screen and Preview video (30 s) records 30 seconds at 60 fps with the game's sound. They are saved where the frontend looks for the game's art (~/media/snap and ~/media/preview, in the game's folder), so the frontend shows the new picture and video next time. The menu closes first so it is not in the capture, a blue bar tells that it is recording, that it saved or why it failed, and the menu shortcut stays off while it records. The video's sound needs the live screen sound turned on; otherwise the file has a silent track.
- On-screen menu: Configuration now has a gear icon, and Close is now called Close OSD menu.
