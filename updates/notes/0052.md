- Party play between cabinets (wired local network only, no internet): "net play" is now called party. Each cabinet has a name (Setup > System > Cabinet name, also asked during the installation; with none, a fruit or an animal of its own), shown in the waiting room and in a notice with a bell when another cabinet opens a party: "NAME IS PLAYING". A RetroArch party starts as soon as it is opened and the others join the game while it runs.
- Flycast party (Naomi and Atomiswave) for up to 4 players on 2 to 4 cabinets, each with its own controllers, in lockstep like an arcade link board: the cabinets stay a frame apart and the faster one waits a few ms for the others' input each frame, for one frame (17 ms) of input delay. The party starts from the factory saved memory on every cabinet and gives each one its own back at the end. This updates the Flycast package (the FliperOS lockstep patch); a cabinet with a Flycast built by hand gets the package back.
- The buttons of the frontend's windows (START, LEAVE, CANCEL) are now buttons, with the panel button and the label inside.
- Light gun in every RetroArch core that has one: FBNeo, PlayStation, SNES, Mega Drive, Master System, NES (Nestopia and Mesen's Zapper too); the players stay on their pads with a gun plugged in.
- RetroArch: a game whose folder's core is not installed downloads the core first.
- DuckStation: PAL games at 50 Hz on the tube, no field flicker in 240p, the window starts at the mode's size, the default crop (one game line per tube line), and no main window before the game.
- Frontend: left and right move only the system tiles and the list changes on a pick, with the system strip zooming smoothly and closing when you go back to the same system; switching systems no longer closes the frontend; the new list comes in piece by piece, with double door, mosaic and pop by default (Tab > Transition picks); the automatic scrape box leaves once every art pack is done.
- Download BIOS: when RetroBIOS lacks the checksum of a file, it is found by its name and set.
- Arcadeflow shows the FliperOS logo on its splash screen.
