- Download BIOS: any Flycast game (Dreamcast, Naomi, Naomi 2, Atomiswave or the RetroArch Flycast core) now brings every BIOS Flycast uses into ~/bios/dc: naomi.zip, naomi2.zip, naomigd.zip, awbios.zip, segasp.zip, dc_boot.bin, dc_flash.bin and the game boards (airlbios, f355bios, f355dlx, hod2bios). Before, the Naomi BIOS came only for the sets the MAME list knew, and a Naomi game could stop with "cannot load BIOS naomi". The automatic check fetches them on its own; Setup > Games > Downloader > Download BIOS does it right away.
