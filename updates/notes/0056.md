- Wine games get the interlaced flicker filter and the on-screen menu, also 32-bit Windows games and games that draw in Vulkan (DXVK). Installing Wine from Setup > Games > Extras builds the 32-bit filter; this update builds it where Wine is already installed.
- Custom games: each one has its own flicker filter level (a row in Video Setup > Interlaced hacks, and the on-screen menu keeps the level for that game). A new custom game gets a sample picture, video, text and logo with its name, so it shows up with art in the frontend; the Setup says which files to replace in ~/media. Renaming a custom game takes its media along. This update makes the samples for the custom games you already have.
- Custom games > Pack a game folder: a PC game with thousands of files becomes one compressed file (squashfs), mounted in the same place, so it runs as before and can still save in its folder. It can be unpacked back.
- Setup > Games > Extras > Wine Staging: the newest Wine, from WineHQ, with fixes that are not in Wine yet, so more Windows games run. It takes the place of Wine, and Fightcade uses it too.
- The FliperOS frontend shows the description in ~/media/texto for games without an arcade history.
