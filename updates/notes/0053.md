- RetroArch: the D-pad of a controller set in Setup > Joysticks > Button mapping now works in RetroArch even when RetroArch has no ready profile for that controller (8BitDo Ultimate and many other gamepads whose D-pad is a hat). Before, only the buttons answered. The update saves your button mapping again; if the controller was off while the update ran, turn it on and save the Button mapping once more.
