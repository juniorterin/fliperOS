- MAME 2010 (the RetroArch arcade core): the unlocked arcade memory now comes for it too, as it already did for GroovyMAME. It covers Tekken 3, Tekken Tag Tournament, Soul Edge, Soul Calibur, Dead or Alive++, Street Fighter EX and EX 2, Street Fighter Alpha 3, Rival Schools, Star Gladiator 2, Kikaioh (Tech Romancer) and Ultimate Mortal Kombat 3. MAME 2010 keeps the memory of a game in one `<set>.nv` file, so they go to `~/nvram/retroarch/mame2010` at the next login, one time per game. A game that already had a memory of its own (the factory one it writes the first time it opens) gets the unlocked one, and its own is kept in `.own` in that folder. Tekken 3 was checked on a cabinet; Marvel vs. Capcom 2 and Mortal Kombat II are not included (their memory could not be brought over safely to that version of MAME).
