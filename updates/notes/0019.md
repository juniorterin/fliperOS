- **Faster boot**: the services set to "After boot" (Setup > System > Services) now start about 15 s after the first screen opens (menu, frontend or game), instead of 40 s after the boot. With no screen at all they still start 3 minutes after the boot, so SSH and the web panel always come up.
- The network share (Samba) is "After boot" by default: it alone took about 13 s of the boot. You can set it back to "Boot" in Setup > System > Services.
- The Downloader's torrent service no longer starts at boot: it starts when you ask for a download (a magnet link, a `.torrent` file or an art pack) and quits by itself when the last torrent finishes. A download stopped by turning the cabinet off goes on with "Start the download".
