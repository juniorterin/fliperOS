- USB Wi-Fi adapters that start as a CD-ROM with their own drivers (the Realtek RTL8188GU, `0bda:1a2b`, and similar ones) now switch to Wi-Fi by themselves when plugged in. The system gets `usb-modeswitch` and its rules (`usb-modeswitch-data`), and this update installs them. An adapter that is already plugged in has to be unplugged and plugged in again once. In Setup > Wi-Fi, when no adapter is found, the list of network hardware now says so if one is still showing as a driver CD-ROM. Not tried yet with a real adapter.
- FliperOS is written FliperOS everywhere, never in capital letters, and the "OS" has another colour where the name is drawn: the Setup and the frontend (titles, hints, warnings), the web panel (login, the cabinet's marquee, the section titles), the on-screen menu, the ZeDMD startup animation and the marquee animation. The machine, folder and user names (`fliperos.local`, `\\fliperos\roms`, `fliperos@ip`) stay the same.
- Web panel, custom games: one Games page. Sending a zip installs it into the group you choose (deleting the zip afterwards is a checkbox, not a question). There is a filter at the top, the packages waiting to be installed sit above the groups, and every game is a full card with Open, edit, download and a menu.
- Web panel, custom games: an installed game can be edited in one form: mode, information, executable and runner (Windows games), command (Linux games), controller map (keep, erase or joystick) and art. The art has the same capture tray as Create package (a photo and 30 seconds of video of the cabinet's screen), a preview and Test on the cabinet, which opens the installed game. Closing the form closes the game it opened, if that is still the one on screen. The controller picker shows an icon per type (directions as arrows, aim, axes, keyboard).
- Web panel, custom games: Download on an installed game rebuilds the package with the settings and the `.key` file that changed after the install. If the zip already carries the same, nothing is redone. A zip whose name is not the game's is only replaced when forced.
- Web panel, custom games: Create package makes one package, or many at once in a table (details per row, apply to all, cards when the screen is narrow). When it is done it asks whether to install it, and in which group.
- Web panel, custom games: a group's name and logo are edited in one form, and a new group already lets you choose the logo while you name it: upload an image or pick one of the logos FliperOS already has, with a preview. If the image does not fit, the group is still created, without a logo, and the message says why.
- Web panel: Play opens a custom game now, on both pages. Before, the cabinet ignored the request (it only opened requests that start with `fliperos-x11-run` or `kms-run`), so Play never opened them. Close also sees a custom game that is open: a Windows game (Wine, PortProton) has no emulator name, so Close answered "closed 0" and Playing another game did not close it.
- Web panel: Playing now, the marquee preview and the volume sit in one aligned grid. Before they were two grids that did not line up: there was a gap under Playing now, and Volume and Behind the game stood outside the columns above. Now Playing now is on the left with the volume right under it, and the marquee preview stretches to the end of the column on the right (in a row on a narrow screen). On the Games page the showcase bar (search, filters, clones, grid/list) has one height. Filters that do not fit fade at the edge and show an arrow that scrolls, like the tabs, and the chosen filter always comes into view. Clones are a switch with a box, apart from the filters. On a game's sheet, "Open when the cabinet turns on" is a row of the facts grid with a sentence about what it does, the cards above have more room, and "1 times" now reads "once".
- On-screen menu: opening a page that takes a moment (Colour, Scanlines, Geometry and GunCon 2 read the Setup or do calculations when you press Enter) no longer leaves the menu still with nothing drawn. Those Enters now run in the background and the keys wait for the page to open, so they do not fall on the page before it. After a quarter of a second a small ring with a spinning comet shows in the title corner (the comet of the achievements circle, small), and it goes away when the page opens; what is quick does not flash. The buttons that go to the Worker's queue (Save and Use the default in Geometry, Back to the defaults in Colour, Scanlines and GunCon 2) show the ring until they finish, without holding the keys. A page that does not open does not hold the menu (COULD NOT OPEN), and waiting for a page does not count as idle for the 20 seconds after which the menu closes.
