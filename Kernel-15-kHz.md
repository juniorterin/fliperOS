`fliperos-kernel.sh` downloads kernel.org **6.18.54**, applies `patches/kernel-15khz/6.18/` (D0023R, 01 to 09) on top of the `.config` of Ubuntu 24.04's own kernel and builds the `.deb`s. No module signing and no debug info. Compiling takes hours, so the `.deb`s stay in a cache keyed by version and patch hash (`/output/kernel-cache/<key>/`): the next build reuses them.

Switchres (`v2.2.1`, the same version as GroovyArcade's package) is compiled with `grid` and `geometry`, and at build time generates one EDID per monitor preset plus the two super resolution ones used by the boot's EDID entries (`fliperos-rebuild-edids`, GroovyArcade's `rebuild_edids`). The initramfs hook carries all of them into the initramfs.
