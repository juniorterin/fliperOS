🇺🇸 **FliperOS 0.22 is out** 🕹️

MAME games get party play: cabinets on the wired local network play the same GroovyMAME game with every player it has (up to 10), each cabinet with its own controllers, on the same frame like an arcade link board and with no input delay. Flycast's party (Naomi and Atomiswave) runs in lockstep too, for up to four players. Also in this ISO: a name for each cabinet, Flycast updated over the network, the newest emulators from the Setup, the light gun in every RetroArch core, the flicker filter in Wine games and Wine Staging.

Cabinets already installed get all of this from the Setup's own update (updates 47 to 57).

ISO and the full list of changes: [release 0.22](https://github.com/juniorterin/fliperOS/releases/tag/0.22)

🇧🇷 **Party do MAME em lockstep**

A cada quadro emulado, cada gabinete manda os controles dos seus jogadores e espera os dos outros do mesmo quadro: todos rodam o mesmo jogo no mesmo quadro, como uma placa de link. No cabo a ida e volta leva menos de 1 ms, então não há atraso de entrada. Todos começam da memória e dos ajustes de fábrica do jogo, no mesmo relógio, e os recordes de cada um ficam como estavam.

🇺🇸 **MAME party in lockstep**

Every emulated frame, each cabinet sends its players' controls and waits for the others' of the same frame: all of them run the same game on the same frame, as a link board does. On the cable a round trip takes under 1 ms, so there is no input delay. Every cabinet starts from the game's factory memory and settings, on the same clock, and each one's own scores stay as they were.

🇺🇸 **Tested with Super Street Fighter II Turbo**

Between a cabinet and a PC, with a script on each machine that coins, picks a character and fights with random moves. In 9 matches the game's memory was the same on both machines every second, and the screens taken on the same frames were identical byte for byte. This screen is the cabinet's; the PC's on the same frame is the same.
