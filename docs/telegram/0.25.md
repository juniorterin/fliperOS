🇺🇸 **FliperOS 0.25 is out** 🎮

**Custom games** are the heart of this version: any game that isn't a ROM (a Windows game through PortProton, a Linux game, a PC port, a homebrew) joins the cabinet like a system of its own, with its picture, video, text and controls in the FliperOS frontend. Each game travels as one file, GAME.fliperos-customgame.zip, installed from the Setup or the web panel. The panel also makes the packages, tests the game on the cabinet before packing it and adds many games at once in a table. Also in this ISO: the wheel calibration redone, with a new screen for pedals, buttons and force feedback; achievements on screen and in the frontend; game shortcuts; the whole Setup in the web panel; and faster cloud backup.

Cabinets already installed get all of this from the Setup's own update (updates 67 to 77).

ISO and the full list of changes: [release 0.25](https://github.com/juniorterin/fliperOS/releases/tag/0.25)

🇧🇷 **Jogos custom em pacotes**

Instalar pacotes mostra os cartões como no frontend (imagem, vídeo, texto e controles), com busca e filtro. Criar pacote junta a pasta do jogo, a arte, o modo de vídeo, os controles e o mapa do controle para teclado, mostra a prévia do cartão e deixa testar o jogo no gabinete antes de empacotar. Uma pasta já montada como pacote preenche tudo sozinha.

🇺🇸 **Custom games in packages**

Install packages shows the cards like the frontend does (picture, video, text and controls), with search and filter. Create package gathers the game folder, the art, the video mode, the controls and the controller-to-keyboard map, shows a preview of the card and lets you test the game on the cabinet before packing it. A folder already laid out like a package fills everything in by itself.

🇧🇷 **Muitos jogos de uma vez**

No painel web, uma tabela adiciona vários jogos custom juntos: digitados, escolhidos em listas, importados de uma pasta com uma subpasta por jogo ou colados de uma planilha. A verificação marca cada célula errada com o motivo. Os jogos de Windows rodam no PortProton, e um jogo de PC que só aceita teclado ganha o Controller configuration no menu na tela: você escolhe a tecla de cada botão.

🇺🇸 **Many games at once**

In the web panel, a table adds several custom games together: typed, picked in lists, imported from a folder with one subfolder per game, or pasted from a spreadsheet. The check marks each wrong cell with the reason. Windows games run in PortProton, and a PC game that only takes the keyboard gets Controller configuration in the on-screen menu: you choose which key each button sends.

🇧🇷 **Volante, pedais e force feedback**

A calibração do volante fechava sozinha assim que o volante girava; agora não. No Setup gráfico, uma tela nova sobre o fundo do menu: o volante gira com o seu, em graus, os pedais enchem, depois cada botão acende no lugar real dele no desenho do controle, e o force feedback puxa para os dois lados e treme.

🇺🇸 **Wheel, pedals and force feedback**

The wheel calibration closed by itself as soon as the wheel turned; not anymore. In the graphical Setup, a new screen over the menu's background: the wheel turns with yours, in degrees, the pedals fill up, then every button lights up in its real place on the drawing of the controller, and the force feedback pulls both ways and shakes.
