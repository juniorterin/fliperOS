🇺🇸 **FliperOS 0.26 is out** 🎮

**One disk for everything, Keisho for Model 2 and Model 3, and a smoother frontend.** A second or external disk now holds the ROMs, BIOS, art, saves and downloads (Setup > System > Storage). Keisho runs Model 2 and Model 3, and Supermodel is gone. The frontend no longer stalls when switching systems, and the web panel shows all of the machine's hardware, with a button that copies the report for a help request.

Cabinets already installed get all of this from the Setup's own update (updates 78 to 85).

ISO and the full list of changes: [release 0.26](https://github.com/juniorterin/fliperOS/releases/tag/0.26)

🇧🇷 **O hardware do gabinete, no painel web**

System > Status mostra a placa-mãe, a CPU e o socket, o cache, a memória, os discos com as partições, as placas de som (e qual é a saída em uso), os aparelhos ligados e os endereços PCI. **Copy full report** copia tudo isso, mais as configurações do Setup, o fliperos.conf e os pacotes, pronto para colar num pedido de ajuda (sem endereços IP nem MAC). Logs ganhou o botão de copiar o log.

🇺🇸 **The cabinet's hardware, in the web panel**

System > Status shows the motherboard, the CPU and socket, the cache, the memory, the disks with their partitions, the sound cards (and which one is the output in use), the connected devices and the PCI addresses. **Copy full report** copies all of that, plus the Setup's settings, fliperos.conf and the packages, ready to paste into a help request (no IP or MAC addresses). Logs got a button to copy the log.

🇧🇷 **Frontend mais suave, e um disco a mais**

Trocar de sistema não trava mais: os arquivos dos emuladores, a arte dos jogos e os ícones são lidos em segundo plano. O primeiro botão depois de um tempo parado vale (antes só acordava a tela).

**Setup > System > Storage:** um disco de dados que você liga ganha a pasta `fliperos` com toda a estrutura, e um toque faz as ROMs, a arte, os saves e os downloads irem para ele. "Back to the main disk" desfaz, e nada é apagado.

🇺🇸 **A smoother frontend, and one more disk**

Switching systems no longer stalls: the emulators' files, the games' art and the icons are read in the background. The first button after the cabinet sat idle works (before, it only woke the screen).

**Setup > System > Storage:** a data disk you plug in gets the `fliperos` folder with the whole structure, and one tap sends the ROMs, art, saves and downloads to it. "Back to the main disk" undoes it, and nothing is deleted.
