🇺🇸 **Group bot: a package with a wrong name gets a warning** 🤖

Some packages reached the group with a changed name, like `COTTOn_RockWithYou_ORIENTAL_NIGHT_DREAMS_fliperos_customgame_zip.002`: some program (the sender's Telegram app, or the browser that downloaded the part) turned the dots and hyphens into `_`. The cabinet does not recognise such a file: neither the double-click, nor the Setup, nor the panel installs it.

Now the bot answers a file like that saying the name is invalid and showing the right one (one tap copies it). Rename it and send it again: then the usual card comes out. The right name ends in `.fliperos-customgame.zip`, and each part of a split package in `.fliperos-customgame.zip.001`, `.002`...
