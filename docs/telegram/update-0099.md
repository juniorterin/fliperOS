🇧🇷 **Atualização 99 do FliperOS: os jogos de OpenBOR abrem no RetroArch, com o core AnyBOR** 👊

Os `.pak` do OpenBOR agora abrem no **AnyBOR**, um core libretro do OpenBOR com **322 perfis de motor** (do OpenBOR 3.0 build 3020 ao 4.0 8023-dev) que escolhe sozinho o perfil de cada pak: mods antigos e novos abrem no mesmo core, no RetroArch, com o modo de vídeo da CRT, save states e até 4 jogadores.

🇺🇸 **FliperOS update 99: OpenBOR games open in RetroArch, with the AnyBOR core** 👊

OpenBOR `.pak` files now open in **AnyBOR**, a libretro core for OpenBOR with **322 engine profiles** (from OpenBOR 3.0 build 3020 to 4.0 8023-dev) that picks the profile for each pak by itself: old and new mods open in the same core, in RetroArch, with the CRT video mode, save states and up to 4 players.

---

![](docs/telegram/img/update99-anybor-gunman.png)

🇧🇷 **Instala sozinho, só quando alguém for jogar**

- O core não vem na imagem: na primeira vez que você abre um jogo de OpenBOR no frontend, o FliperOS baixa e instala o pacote (uns 5 MB, com a barra de progresso) e o jogo abre.
- `~/roms/openbor` virou um atalho para `~/roms/retroarch/anybor`, a pasta do core. Quem já tinha jogos em `~/roms/openbor` tem tudo movido para lá, um arquivo de cada vez, sem sobrescrever nada.
- O motor de **Setup > Games > OpenBOR** continua como era.

🇺🇸 **It installs itself, only when someone plays**

- The core is not in the image: the first time you open an OpenBOR game in the frontend, FliperOS downloads and installs the package (about 5 MB, with the progress bar) and the game opens.
- `~/roms/openbor` is now a shortcut to `~/roms/retroarch/anybor`, the core's folder. Whoever had games in `~/roms/openbor` gets everything moved there, one file at a time, nothing overwritten.
- The engine of **Setup > Games > OpenBOR** stays as it was.

🇧🇷 **Testado no gabinete**

Gunman (400x300), Batman SD (320x240) e Moonblade (640x480) abrem no AnyBOR, cada um no tamanho que o pak pede. O core inclui o OpenBOR 3400 e 3741, cuja licença proíbe vender o código; os textos das licenças vão dentro do pacote.

🇺🇸 **Tested on the cabinet**

Gunman (400x300), Batman SD (320x240) and Moonblade (640x480) open in AnyBOR, each at the size the pak asks for. The core includes OpenBOR 3400 and 3741, whose license forbids selling the code; the license texts ship inside the package.
