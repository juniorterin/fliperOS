Rules

Two languages
Every string is in English and Portuguese: config/web/text.js and setup-text.js have the same keys (a test counts them); the Setup is English only, the web panel and the frontend are bilingual where they are for the person.
Text that does not fit runs
Never cut text on a screen: the selected row runs (feview.ticker, scroll_text); a hint fits 2 lines of 34 columns.
Every menu item has an icon
A new Setup item gets a drawing in gui/theme.py (GuiMenuIconTests) and an px-ID in icons.svg for the web.
Anything over a game is responsive
The OSD and the notices adapt to every frame size and to the vertical monitor; preview with the real fit()/layer_view().
Screenshots in proportion
Never a stretched print: 640x240 is shown 4:3 (releases, the site, Telegram).
Colours are roles
Use the role of the table above, not a colour you like; the web uses var(--token), never the hex.
One place for each thing
A panel setting is a row of the Setup tree (setup.js) with the same id as the Setup menu; a parity test fails when one is missing.
Fixes are general
Never a mapping for one person's panel or game: fix the class of problem.
